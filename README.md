# Task Deadline Tracker

## Goal
Task Deadline Tracker is a small task management app for tracking todos, deadlines, progress, and task archives.

## Features
- Create tasks with a title
- Add optional task descriptions
- Add optional deadlines with date and time
- Show open tasks sorted by nearest deadline
- Display remaining time until a deadline
- Display deadline progress with a progress bar
- Mark tasks as completed
- Move completed tasks to an archive
- Reopen completed tasks
- Delete tasks
